## [0.1.0] - 2026-10-12

- Browse containers, images, volumes and networks locally or over SSH.
- Open Docker views from the GNOME Files context menu with matching host selection.
- Search, sort columns and inspect resource details in a native GTK interface.
- Manage SSH connections and optional non-interactive sudo access.
- List, add, edit and remove SSH connections from a CLI without requiring GTK or a display.
- Authorize a window-scoped local session through PolicyKit, or install optional read-only systemd access.
